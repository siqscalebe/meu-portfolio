# Landing Page — Portfólio pessoal

Projeto acadêmico feito com HTML5 e CSS3, contendo cinco páginas conectadas:
- `index.html` — Home
- `curriculo.html` — Currículo
- `github.html` — GitHub e projetos
- `servicos.html` — Serviços e tabela de preços
- `contato.html` — Formulário com diferentes tipos de campos
- `style.css` — Estilos responsivos compartilhados

## Antes de entregar
1. Substitua os campos entre colchetes pelos seus dados verdadeiros.
2. Troque a imagem de exemplo por uma foto sua, se desejar.
3. Na página `github.html`, troque `https://github.com/` pelo link do seu perfil.
4. Revise preços e informações para que estejam de acordo com o que deseja apresentar.
5. O formulário é demonstrativo: ele valida os campos no navegador, mas não envia nem armazena os dados.

## Publicar com GitHub Pages
1. Crie um repositório público no GitHub.
2. Envie todos os arquivos mantendo a mesma estrutura.
3. Abra **Settings → Pages**.
4. Em **Build and deployment**, selecione **Deploy from a branch**.
5. Escolha a branch `main` e a pasta `/ (root)` e clique em **Save**.
6. Aguarde a publicação e copie o link mostrado na área Pages.
